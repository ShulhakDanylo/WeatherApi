# 🌦️ WeatherFlow — Локальна система чисельного прогнозування погоди

Автономний програмний комплекс для мікролокального моделювання, аналізу та тривимірного прогнозування динаміки атмосфери на основі систем диференціальних рівнянь у частинних похідних — керований високопродуктивним .NET бекендом та адаптивним React-інтерфейсом.

## 🏗️ Архітектура системи (System Architecture)

Система побудована на базі сучасної триланкової клієнт-серверної архітектури, де вебзастосунок виступає в ролі клієнта, взаємодіючи з обчислювальним сервером через асинхронні RESTful HTTP APIs за допомогою JSON-пакетів.

## 🔧 Основні компоненти (Main Components)

### 🎨 Вебклієнт (React SPA)
* Побудований на базі **React** для забезпечення високої швидкодії та чуйності інтерфейсу.
* Містить інтерактивний аналітичний дашборд (Dashboard) для візуалізації погодних полів.
* Відображає динамічні графіки, часові ряди та матричні сітки прогнозу з колірною індикацією.
* Асинхронно взаємодіє з бекендом, виключаючи перезавантаження сторінок під час зміни ітерацій розрахунку.

### ⚙️ Обчислювальний сервер (ASP.NET Core / .NET 9)
* Спроектований на базі **.NET 9** та **ASP.NET Core** для забезпечення максимальної швидкості математичних обчислень.
* Містить ізольовані фонові обчислювальні сервіси:
  * `TemperatureSolverService` — моделювання термодинамічних змін поля температур.
  * `AtmosphericLevelService` — розрахунок рівнів вологості та переносу вологи.
  * `PressureSolverService` — обчислення динаміки баричного поля та тиску.
  * `WindSolverService` — моделювання векторів швидкості вітру.
* Автоматично інтегрується із зовнішніми джерелами через `HttpClient` для фіксації початкових умов.

### ☁️ Модуль ініціалізації початкових умов (OpenWeather API)
* Використовує асинхронні запити до **OpenWeather API**.
* Імпортує реальні метеорологічні метрики для обраних географічних координат.
* Формує базовий масив початкових значень (задачу Коші), після чого обчислювальне ядро переходить у повністю автономний режим симуляції.

### 💾 База даних (PostgreSQL)
* Використовує реляційну СКБД **PostgreSQL** для надійного збереження даних.
* Взаємодія реалізована через ORM-фреймворк **Entity Framework Core**.
* Зберігає:
  * Координати та конфігурації просторових обчислювальних сіток (регіонів).
  * Результати успішно згенерованих 7-денних прогнозів (історію симуляцій).
  * Профілі користувачів та логи доступу до системи.

## 📌 Функціональні можливості (Features)

### 📐 Дискретизація простору й часу
* Заміна неперервної (континууму) атмосфери дискретною моделлю — розрахунковою сіткою.
* Просторове розбиття на вузли з фіксованим кроком h = 50 000 метрів.
* Тимчасове просування вперед з дискретним часовим кроком Δt.

### 🧮 Математичне моделювання (Physics Engine)
* Апроксимація неперервних похідних скінченно-різницевими відношеннями між поточним вузлом та його географічними сусідами.
* Застосування правосторонніх скінченних різниць (forward differences) для розрахунку градієнтів за просторовими напрямками (x та y).
* Зведення диференціальних рівнянь атмосфери до СЛАР вигляду Ax = b та її розв'язання ітераційним **методом Гаусса-Зейделя**.
* Врахування сили Коріоліса (планетарного обертання), адвекції, дифузії та термодинамічних законів стану.

### 📊 Аналітика та верифікація
* Генерація автономного прогнозу погоди на семиденний інтервал.
* Верифікація результатів моделювання шляхом порівняння з реальними історичними даними.
* Розрахунок критерію точності за метрикою **nRMSE** (нормалізована середньоквадратична похибка) для оцінки стабільності збіжності алгоритму.

## ✅ Результати моделювання (Results)

* **Висока обчислювальна стійкість:** Розроблена різницева схема та ітераційний алгоритм демонструють швидку збіжність на всьому інтервалі розрахунку.
* **Мінімальне відхилення:** Акумульована похибка округлення на фінальних етапах 7-денної симуляції залишається в межах норми, підтверджуючи фізичну адекватність побудованої математичної моделі.
* **Практична цінність:** Створено повністю незалежне, автономне програмне забезпечення, здатне виконувати мікролокальне метеорологічне прогнозування на базі стандартного серверного обладнання без залучення суперкомп'ютерів.
